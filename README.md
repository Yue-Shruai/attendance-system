# 考勤管理系统

一个简单的学生考勤管理工具，支持：

- 👥 学生管理（添加/删除学生）
- 📝 考勤记录（选择日期，勾选学生签到）
- 🔍 查询统计（选择学生、日期区间，显示上课次数）
- 📱 手机友好界面

## 使用方法

### 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

然后在浏览器打开 http://localhost:8501

### 在线访问

访问：https://Yue-Shruai.github.io/attendance-system

## 技术栈

- Python + Streamlit
- 数据存储：JSON 文件
